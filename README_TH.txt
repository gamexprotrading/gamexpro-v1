GAMExPRO TRADING V1 — iPhone PWA Simulator

สำคัญ: ระบบนี้จำลองเท่านั้น ใช้ราคาสมมติ ไม่มีข้อมูลตลาดสด ไม่เชื่อม Exness/MT5 และไม่ส่งคำสั่งซื้อขายจริง

เผยแพร่ฟรีจาก iPhone ผ่าน GitHub Pages:
1. เปิด github.com ใน Safari และสมัคร/เข้าสู่ระบบ
2. สร้าง Public repository ชื่อ gamexpro-v1
3. อัปโหลดไฟล์ทั้งหมดจาก ZIP โดยคงโครงสร้างเดิม
4. ไป Settings > Pages > Deploy from a branch เลือก main และ /(root) แล้ว Save
5. รอ GitHub Pages แสดง URL HTTPS แล้วเปิด URL ใน Safari
6. กด Share > Add to Home Screen > Add

ฟังก์ชัน: Dashboard, ราคาสมมติ XAUUSD/BTCUSD, Auto Scalping simulation, Risk budget 0.5%, TP $2, SL budget 0.5% ของ balance ณ ตอนเปิด, ประวัติ, Start/Stop, Reset

ราคาและออเดอร์สร้างแบบสุ่มเพื่อทดสอบหน้าจอ ไม่ใช่ backtest และไม่ใช่การคาดการณ์กำไร ห้ามใส่รหัสผ่าน/API key/ข้อมูลบัญชีโบรกเกอร์ใน repository
